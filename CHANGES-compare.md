# Обновление: страницы сравнений (Accio Work vs ...)

Добавлен новый раздел сайта под коммерческие запросы вида «accio work vs ...». Это нижняя часть воронки, где пользователь уже выбирает инструмент, поэтому конверсия в переход по реф-ссылке тут выше всего.

## Что появилось

Хаб сравнений и три страницы, на всех 9 языках (en, ru, de, it, es, zh, pt, hi, fr):

- `/compare` — хаб со всеми сравнениями
- `/compare/chatgpt` — Accio Work против ChatGPT
- `/compare/manus` — Accio Work против Manus
- `/compare/genspark` — Accio Work против Genspark

Локализованные версии по префиксу языка: `/ru/compare`, `/ru/compare/chatgpt` и так далее для каждого языка.

Каждая страница содержит: вводный текст, таблицу сравнения по 6 критериям, блок «когда лучше Accio Work» и честный блок «когда логичнее конкурент» (это повышает доверие и E-E-A-T), вывод, 3 вопроса FAQ и две кнопки с вашей реф-ссылкой. Реф-ссылка `IC506004212009` везде без изменений.

## Как добавить ещё конкурента (например n8n)

Достаточно дописать блок в `src/lib/compare-data.ts` через генератор `gen_compare_data.py` (добавить slug в список и тексты по языкам), затем добавить slug в массив `competitors` в `sitemap.xml`. Отдельные файлы маршрутов создавать не нужно: страница конкурента это динамический маршрут `compare.$competitor`, он подхватит новый slug автоматически.
