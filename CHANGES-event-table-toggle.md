# Страница событий: видимость таблиц + переключатель тем в шапке

## Таблицы сравнения «Сколько стоит запустить магазин»
Внутренняя обёртка таблиц была bg-white/70 (светлая панель), а текст строк на text-foreground (в тёмной теме светлый) = светлый на светлом, почти невидим.
- Обёртку таблицы перевёл на bg-card (тема-зависимая: тёмная в тёмной теме, белая в светлой), теперь строки читаются.
- Строку «Итого» сделал bg-foreground/5, чтобы выделялась.
- Серые подписи и заголовки колонок (#6B7280) перевёл на text-foreground/55, гарантированный контраст в обеих темах (10 мест).
- Hover CTA-кнопки заменил с bg-white/90 на мягкий bg-foreground/10.

## Переключатель тем в шапке
У этой страницы своя шапка (отдельная от общей). Добавил в неё переключатель светлой/тёмной темы рядом с меню языка, тот же общий компонент ThemeToggle. Теперь тумблер есть и на странице событий.
