# Само-обновляемые рыночные алерты

Алерты на странице событий теперь можно править без пересборки сайта, и они сами прячутся по сроку.

## Как работает
1. На сервере (SSR) показываются встроенные честные алерты, локализованные на 9 языков. Это безопасно для SEO и исключает вспышку пустоты.
2. На клиенте страница делает лёгкий REST-запрос к таблице Supabase market_alerts (публичный ключ, только чтение). Если там есть строки для текущего языка, они заменяют встроенные.
3. Авто-скрытие: строка с прошедшим expires_at или active=false не показывается. Просроченные алерты исчезают сами.
4. Graceful fallback: если таблицы нет, база недоступна или пуста, остаются встроенные алерты. Ничего не ломается.

Итог: вы правите алерты в дашборде Supabase (текст, ссылку, картинку, срок), и сайт обновляется на следующем заходе, без деплоя.

## Что нужно сделать один раз
Выполнить supabase/market_alerts.sql в SQL-редакторе Supabase. Он создаёт таблицу, включает RLS на публичное чтение и засевает текущие 3 алерта (en и ru как пример). Дальше добавляете строки для остальных языков и правите через Table editor.

## Поля строки
lang, tag, title, body, cta, href (например /duty или /ru/duty), img (путь к картинке, по умолчанию /img/landing-duty.webp), sort, active, expires_at.

## Безопасность и честность
- Публичный ключ только на чтение, запись через дашборд. RLS отдаёт лишь active=true.
- Никаких выдуманных данных: контент задаёте вы, база лишь позволяет держать его свежим без релиза.

## Техническое
Клиентский REST-фетч без тяжёлого SDK (минимум в бандл). tsc 0, тире нет, сборка зелёная.
