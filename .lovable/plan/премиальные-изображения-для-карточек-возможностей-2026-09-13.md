# Премиальные изображения для карточек возможностей

## Что будет сделано
- Создать единый набор из шести премиальных иллюстраций без текста: AI-агент, браузерная автоматизация, интеграции, генерация контента, Market Scout и специалисты.
- Сохранить фирменную тёмную палитру Accio Work с изумрудными и бирюзовыми акцентами, одинаковым светом и визуальным масштабом.
- Заменить эмодзи в карточках на новые изображения и аккуратно встроить их в верхнюю часть каждой карточки.
- Сохранить текущие тексты и переводы для всех языков.
- Проверить секцию на компьютере и телефоне, включая загрузку изображений, одинаковую высоту карточек и отсутствие обрезанного текста.

## Технические детали
- Изображения будут локальными ассетами проекта с прозрачным фоном, без надписей, логотипов и водяных знаков.
- Для каждой карточки будет задано отдельное локализованное описание изображения для доступности.
- Добавится мягкое приближение иллюстрации при наведении без изменения размеров сетки.
