# Премиальная история об AI-агенте Accio

## Что будет сделано
- Добавить новый содержательный блок сразу после секции возможностей: сначала пользователь увидит, что умеет Accio Work, затем получит наглядное подтверждение полного сценария Accio.
- Выстроить семь изображений в три компактные главы: идея и дизайн; автоматизация запросов; анализ рынка и глобальный поиск поставщиков.
- Адаптировать предоставленное описание в короткие, легко сканируемые тексты без повторов, сохранив ключевые цифры и последовательность «идея → анализ → товар → поставщик → связь».
- Завершить блок заметным призывом скачать Accio и перейти по действующей реферальной ссылке.
- Сохранить премиальный тёмный стиль сайта: крупная типографика, изумрудно-бирюзовые акценты, мягкое свечение и аккуратные изображения интерфейса без лишних декоративных элементов.

## Размещение и адаптация
- На широком экране главы будут чередовать текст и композиции из двух-трёх вертикальных изображений, чтобы интерфейс оставался читаемым.
- На телефоне изображения станут пролистываемой лентой с фиксированной шириной и без обрезки содержимого.
- Для каждого изображения будет добавлено точное описание для доступности; изображения будут загружаться отложенно и получат стабильные размеры.
- Русская версия получит предоставленный смысл полностью; остальные языковые версии получат локализованные тексты, чтобы новый блок не выглядел чужеродным.

## Технические детали
- Загруженные WebP-файлы будут сохранены как CDN-ассеты проекта, без встраивания исходных файлов в репозиторий.
- Новый блок будет отдельным небольшим компонентом внутри главной страницы и не изменит существующие секции, видео или навигацию.
- После внедрения будут проверены компьютерная и мобильная версии, загрузка всех семи изображений, отсутствие горизонтального переполнения и ошибки сборки.
