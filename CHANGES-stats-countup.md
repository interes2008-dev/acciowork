# Живые цифры Accio при прокрутке

Полоса цифр (10M+, 1.5M+, 400M+) теперь анимируется: числа считаются вверх от нуля, когда секция въезжает в зону видимости.

## Как сделано
- Использован уже существующий в проекте хук useReveal (IntersectionObserver, порог 8%). Он залипает в true и отключает наблюдатель после первого показа, поэтому анимация играет один раз.
- Компонент CountUp считает от 0 до значения за 1.3с с плавным замедлением (easeOutCubic) через requestAnimationFrame. Десятичные сохраняются (1.5 остаётся 1.5), суффикс M+ на месте, tabular-nums чтобы ширина не прыгала.
- SSR-безопасно: на сервере и при первом рендере показывается финальное число (одинаково, без рассинхрона гидратации, и корректно без JS). Анимация запускается только на клиенте при появлении.
- Учтён prefers-reduced-motion: при включённом «уменьшении движения» число показывается сразу, без анимации.

## Техническое
Правка только в LandingPage.tsx (компоненты CountUp и AccioStats). Сборка зелёная, tsc 0, тире нет.
